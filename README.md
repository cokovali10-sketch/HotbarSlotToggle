# Hotbar Slot Toggle (5/8)

[![Fabric](https://img.shields.io/badge/Fabric-26.2-d8b400)](https://fabricmc.net/)
[![Java](https://img.shields.io/badge/Java-25-orange?logo=openjdk&logoColor=white)](https://adoptium.net/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Клиентский Fabric-мод: **LeftAlt** переключает выбранный слот хотбара между
**5-м и 8-м**. Предметы не перемещаются — меняется только активный слот.

## Зачем

В PvP и на аренах часто нужны два конкретных слота: например, меч в 5-м и
блоки/еда в 8-м. Тыкать цифры `5` и `8` — это два движения; одна клавиша под
большим пальцем быстрее и не сбивает прицел.

## Как работает

- Мод чисто клиентский: серверу уходит обычный `ServerboundSetCarriedItemPacket`,
  как будто вы нажали цифру.
- Если открыт любой экран (инвентарь, чат, меню) — переключение игнорируется.
- Если текущий слот не 8-й, LeftAlt ведёт в 8-й; если 8-й — обратно в 5-й.
  Так работает «туда-обратно» одной клавишей.

Клавишу можно переназначить в **Настройки → Управление → Инвентарь**
(`key.hotbarswap.swap`).

## Установка

1. Установите **Fabric Loader** и **Fabric API** для Minecraft **26.2**.
2. Положите `hotbarswap-1.0.0.jar` в `.minecraft/mods/`.
3. Запустите игру. Мод работает и на серверах — устанавливать его на сервер не нужно.

Сборка из исходников (JDK 25):

```bash
./gradlew build     # Windows: gradlew.bat build
# build/libs/hotbarswap-1.0.0.jar
```

## Совместимость

| Компонент | Версия |
|---|---|
| Minecraft | 26.2 |
| Fabric Loader | ≥ 0.19.5 |
| Fabric API | любая для 26.2 |
| Java | 25 |

Конфликтов с другими HUD/инвентарными модами нет: мод не миксинится в инвентарь,
а только отправляет пакет смены слота.
